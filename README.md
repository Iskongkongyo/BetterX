## ✨ 什么是 BetterX

刷 X 时你是不是遇到过这些糟心事：

- 刚刷到一条想看的帖子，手一滑就再也找不到了；
- 一些账号发完帖秒删（“闪现”），根本来不及看；
- 时间线里夹杂着大量广告；
- 回复区和推荐流里混着黄推、成人引流机器人；
- 想保存图片 / 视频，还得一张张右键；
- 敏感内容被“年龄限制”遮罩挡住，点“显示”只弹二维码。

**BetterX** 把这些痛点一次性解决。它会在后台记录你滑过的帖子（全部保存在本地，不上传服务器），并提供可拖动的侧边面板，方便随时回溯、搜索和管理。

此外，还可以自定义**用户主页默认页签**，进入主页时自动打开“帖子 / 全部 / 亮点 / 视频 / 图片”，并可单独设置帖子按“最近 / 热门”排序。

## 🚀 功能一览

### 📝 帖子记录与回溯

- **自动收藏时间线**：自动捕获出现在时间线里的帖子（作者、正文、媒体、时间、链接）。
- **全文搜索**：按作者 / 正文 / 备注快速检索。
- **顺序回溯排序**：智能排序保留置顶、收藏与快速消失优先；还可按最近浏览、最近抓取、首次抓取（新→旧 / 旧→新）、出现次数、作者或来源排序。帖子进入可视区后会记录浏览时间，便于找回刚看到的内容。
- **筛选器**：全部 / 未打开 / 快速消失 / 已收藏 / 已置顶 / 已打开 / 命中关键词。
- **媒体筛选**：全部 / 含图片 / 含视频 / 纯文字。
- **来源识别**：区分主页 / 详情 / 搜索页 / 书签 / 通知 / 列表，面板使用中文来源名称，并可设置忽略指定来源。

### 🏷️ 整理与标记

- **置顶 / 收藏 / 备注**：重要帖子置顶，喜欢内容加星，随手写下自己的备注。
- **正文折叠**：长文自动折叠，面板更清爽。
- **闪现提醒**：发帖后很快删除的“快速消失”帖子会被特别标记，阈值可自定义。
- **关键词高亮与过滤**：支持普通、**AND 多词**、**正则**三种模式，另可设置**排除词**（命中即隐藏）。

### 🛠️ 体验增强

- **内容净化**：隐藏黄推、成人引流机器人和广告，支持强度、白名单与自定义屏蔽词。
- **界面净化与宽屏**：可隐藏侧栏、推广、消息栏 / Grok，并调整时间线宽度。
- **媒体下载**：一键下载图片、视频和 GIF，多媒体可自动打包 ZIP，并支持自定义文件名。
- **媒体显示优化**：支持多媒体网格视图，并可在本地解除年龄限制遮罩。
- **主页与帖子增强**：支持主页默认页签、帖子“最近 / 热门”排序，以及自动展开长文。
- **通知订阅管理**：可查看、同步并直接开关用户的帖子通知。

### ⚙️ 界面与数据

- **四语言界面**：支持简体中文、繁体中文、日文和英文，可自动跟随页面语言或手动切换。
- **三视图面板**：帖子、通知、设置相互独立，常用筛选与排序集中在帖子页。
- **灵活徽标**：支持拖动、隐藏、移动端唤醒把手，以及桌面圆形徽标。
- **Firefox 兼容模式**：遇到 X 启动异常时可一键切换兼容模式。
- **主题与快捷键**：支持明 / 暗 / 跟随系统主题，并可用 `Alt + X` 开关面板。
- **数据管理**：支持导入 / 导出备份、自动清理和最大记录数限制。
- **本地存储**：帖子与设置保存在浏览器本地，不上传服务器。

## 📦 安装

1. 先安装任意一个油猴类扩展：

   - [Tampermonkey](https://www.tampermonkey.net/)（推荐，Chrome / Edge / Firefox / Safari）
   - [Violentmonkey](https://violentmonkey.github.io/)（基础功能可用；安卓 Firefox 的视频详情请求可能受登录态限制）

   直接从 GreasyFork [更好的 X（BetterX）](https://greasyfork.org/zh-CN/scripts/588748-更好的-x-betterx) 或者 OpenUserJS [更好的 X（BetterX）](https://openuserjs.org/scripts/流萤可爱捏/更好的_X（BetterX）) 安装。 。

2. 打开 [x.com](https://x.com)，页面左/右下角会出现应用徽标，点击或按 `Alt + X` 即可展开面板。

> 支持域名：`x.com` 与 `twitter.com`。

## 🔒 隐私说明

- 帖子记录、备注和设置均保存在浏览器本地，**不会上传到 任何 服务器**。
- 脚本只在 `x.com` / `twitter.com` 运行；联网请求仅用于 X 官方功能，如通知管理和媒体下载。
- “取消年龄限制”与“内容净化”只修改本地页面显示，**不会修改账号设置、自动拉黑或举报用户**。
- 清理浏览器数据可能导致本地记录丢失，建议定期导出备份。

## ❓ 常见问题

**Q：为什么有些帖子没被记录？**  
A：BetterX 只能记录已经在页面中实际加载过的帖子；如果缺少记录，也可检查“高级设置”里是否忽略了对应来源。

**Q：视频下载失败或找不到媒体怎么办？**  
A：先确认已经登录 X，并尝试点开或播放视频后重试。安卓 Firefox + Violentmonkey 若仍无法获取视频地址，建议改用 Tampermonkey。

**Q：为什么多媒体有时不会打包成 ZIP？**  
A：关闭 ZIP 选项、文件过大，或超出浏览器可安全处理的范围时，会自动改为逐个保存。

**Q：取消年龄限制后视频没有显示？**  
A：图片通常可以立即显示；视频需要先获取真实媒体地址，滑到该帖或播放一次后再试即可。

**Q：Firefox 一直停在 X 图标怎么办？**  
A：在“设置 → 其他功能”开启“兼容 Firefox”；如果连面板都打不开，可从油猴脚本菜单强制开启兼容模式并刷新。

**Q：主页默认页签和热门排序会影响账号切换吗？**  
A：不会。它们只作用于普通用户主页；“热门”也只作用于帖子类主页，不影响视频、图片页和账号切换流程。

**Q：宽屏为什么在消息页或设置页无效？**  
A：这两个页面结构与时间线不同，BetterX 会自动停用布局调整，避免页面错位。

**Q：内容净化误隐藏正常帖子怎么办？**  
A：可切换为“保守”模式、开启“不审查已关注账号”，或把账号加入白名单。

**Q：数据会丢吗？**  
A：数据保存在浏览器本地，清理浏览器数据时可能被删除，建议定期导出 JSON 备份。

**Q：记录超过“最大条数”后会怎样？**  
A：BetterX 会继续记录新帖子，并优先删除最旧的未收藏、未置顶记录；收藏和置顶内容会保留。
