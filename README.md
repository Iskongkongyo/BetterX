---

## ✨ 什么是 BetterX

刷 X 时你是不是遇到过这些糟心事：

- 刚刷到一条想看的帖子，手一滑就再也找不到了；
- 一些账号发完帖秒删（“闪现”），根本来不及看；
- 时间线里夹杂着大量广告；
- 想保存图片 / 视频，还得一张张右键；
- 敏感内容被“年龄限制”遮罩挡住，点“显示”只弹二维码。

**BetterX** 把这些痛点一次性解决。它在后台静静记录你滑过的每一条帖子（全部存在本地 IndexedDB，不上传任何服务器），并提供一个可拖动的侧边面板让你随时回溯、搜索、管理。

## 🚀 功能一览

### 📝 帖子记录与回溯

- **自动收藏时间线**：自动捕获出现在时间线里的帖子（作者、正文、媒体、时间、链接）。
- **全文搜索**：按作者 / 正文 / 备注快速检索。
- **多维度排序**：默认、最早优先、捕获次数、作者、来源。
- **筛选器**：全部 / 未打开 / 快速消失 / 已收藏 / 已置顶 / 已打开 / 命中关键词。
- **媒体筛选**：全部 / 含图片 / 含视频 / 纯文字。
- **来源识别**：区分主页 / 详情 / 搜索页 / 书签 / 通知 / 列表，可设置忽略指定来源。

### 🏷️ 整理与标记

- **置顶 / 收藏 / 备注**：重要帖子置顶，喉嗜内容加星，随手写下自己的备注。
- **正文折叠**：长文自动折叠，面板更清爽。
- **闪现提醒**：发帖后很快删除的“快速消失”帖子会被特别标记，阈值可自定义。
- **关键词高亮与过滤**：支持普通、**AND 多词**、**正则**三种模式，另可设置**排除词**（命中即隐藏）。

### 🛠️ 体验增强

- **关闭广告**：自动隐藏含“广告”标记的推广帖。
- **一键下载图片 / 视频 / GIF**：在帖子上直接出现下载按钮；多媒体自动打包为 `zip`，文件名按「用户ID_帖子ID」命名。
- **取消年龄限制**：不去点会弹二维码的“显示”按钮，而是借助媒体采集能力，直接用原图 / 视频把遮罩内联替换，按 X 经典方格马赛克布局展示。

### ⚙️ 界面与数据

- **可拖动徽标**：桌面端悬浮徽标位置可自由拖拽。
- **明 / 暗 / 跟随系统主题**。
- **快捷键** `Alt + X` 一键开关面板。
- **导入 / 导出备份**：一键备份全部数据为 JSON，随时恢复 / 迁移。
- **自动清理**：可按天数自动清理旧记录，并限制最大存储条数。
- **本地持久化**：全部数据存于浏览器 IndexedDB，**不联网、不上传**。

## 📦 安装

1. 先安装任意一个油猴类扩展：
   - [Tampermonkey](https://www.tampermonkey.net/)（推荐，Chrome / Edge / Firefox / Safari）
   - [Violentmonkey](https://violentmonkey.github.io/)
2. 新建一个用户脚本，把 `更好的X.js` 的全部内容粘贴进去保存；或直接从 GreasyFork 安装。
3. 打开 [x.com](https://x.com)，页面左/右下角会出现应用 徽标，点击或按 `Alt + X` 即可展开面板。

> 支持域名：`x.com` 与 `twitter.com`。

## 📖 使用指南

| 操作 | 说明 |
| --- | --- |
| 开关面板 | 点击页面左/右下角的徽标，或按 `Alt + X` |

| 其他功能 | 关闭广告、一键下载媒体、取消年龄限制的开关 |

## 🔒 隐私说明

- 所有帖子记录、备注、设置均**仅保存在你本机浏览器的 IndexedDB 中**，不会上传到任何服务器。
- 脚本仅在 `x.com` / `twitter.com` 运行，网络请求仅用于下载你主动选择的媒体（限于 `twimg.com` 等 X 官方域名）。
- “取消年龄限制”仅在本地 DOM 展示已能获取的媒体，**不会修改你的账号设置**。

## ❓ 常见问题

**Q：为什么有些帖子没被记录？**
A：只有在时间线中实际渲染过（滑到过）的帖子才会被捕获；可在“高级设置”里检查是否忽略了对应来源。

**Q：取消年龄限制后视频没显示？**
A：视频需要从时间线接口采集到真实地址，通常滑到该帖稍等片刻即可；图片则基本即时生效。

**Q：数据会丢吗？**
A：数据存在浏览器本地，清理浏览器数据会一并清除。建议定期用“导出备份”保存 JSON。
