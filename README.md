---

## ✨ 什么是 BetterX

刷 X 时你是不是遇到过这些糟心事：

- 刚刷到一条想看的帖子，手一滑就再也找不到了；
- 一些账号发完帖秒删（“闪现”），根本来不及看；
- 时间线里夹杂着大量广告；
- 回复区和推荐流里混着黄推、成人引流机器人；
- 想保存图片 / 视频，还得一张张右键；
- 敏感内容被“年龄限制”遮罩挡住，点“显示”只弹二维码。

**BetterX** 把这些痛点一次性解决。它在后台静静记录你滑过的每一条帖子（全部存在本地 IndexedDB，不上传任何服务器），并提供一个可拖动的侧边面板让你随时回溯、搜索、管理。

## 🚀 功能一览

### 📝 帖子记录与回溯

- **自动收藏时间线**：自动捕获出现在时间线里的帖子（作者、正文、媒体、时间、链接）。
- **全文搜索**：按作者 / 正文 / 备注快速检索。
- **多维度排序**：默认、最早优先、捕获次数、作者、来源。
- **筛选器**：全部 / 未打开 / 快速消失 / 已收藏 / 已置顶 / 已打开 / 命中关键词。
- **媒体筛选**：全部 / 含图片 / 含视频 / 纯文字。
- **来源识别**：区分主页 / 详情 / 搜索页 / 书签 / 通知 / 列表，面板使用中文来源名称，并可设置忽略指定来源。

### 🏷️ 整理与标记

- **置顶 / 收藏 / 备注**：重要帖子置顶，喜欢内容加星，随手写下自己的备注。
- **正文折叠**：长文自动折叠，面板更清爽。
- **闪现提醒**：发帖后很快删除的“快速消失”帖子会被特别标记，阈值可自定义。
- **关键词高亮与过滤**：支持普通、**AND 多词**、**正则**三种模式，另可设置**排除词**（命中即隐藏）。

### 🛠️ 体验增强

- **隐藏黄推 / 成人引流机器人**：采用多信号评分，只在 DOM 层隐藏；支持保守 / 均衡强度、默认跳过已关注账号的原创内容、可选同时跳过其转发内容，以及自定义字面屏蔽词和账号白名单。关注关系会从 X 接口、主页按钮和“正在关注”时间线学习并仅在本地记忆，供书签等缺少关系字段的页面复用。
- **界面净化与宽屏**：默认自动读取 X 当前的时间线和左侧栏宽度且不改写原生布局；也可切换手动宽度，隐藏左右栏、Premium 推广、页脚、消息栏 / Grok，并支持中间栏真正居中填满。消息页和设置页自动停用。
- **关闭广告**：默认开启，自动隐藏含“广告”标记的推广帖。
- **一键下载图片 / 视频 / GIF**：默认开启，在帖子上直接出现下载按钮；多媒体自动打包为 `zip`，文件名按「用户ID_帖子ID」命名。Firefox 兼容模式保留 DOM 可识别媒体的下载能力，但不拦截页面网络响应，因此部分视频 / GIF 可能无法取得真实地址。
- **取消年龄限制**：不去点会弹二维码的“显示”按钮，而是借助媒体采集能力，直接用原图 / 视频把遮罩内联替换，按 X 经典方格马赛克布局展示。

### ⚙️ 界面与数据

- **帖子 / 设置双视图**：搜索、快速筛选和排序常驻帖子页，设置独立滚动，浏览记录时不再被大量选项挤占空间。
- **设置状态更清楚**：复选框改为直观开关；内容净化与宽屏关闭时，从属选项会自动置灰。
- **清晰易读的界面**：标题、说明、统计、设置文字和帖子元信息按层级使用更易读的字号；桌面标题与移动端徽标复用脚本自身图标。
- **可选圆形桌面徽标**：PC 端可在“其他功能”中切换为移动端同款圆形图标与未读角标，并继续拖拽调整位置。
- **Firefox 兼容开关**：首次在 Firefox 运行时会询问 X 是否能正常打开；若遇到页面一直停在 X 图标，可在“其他功能”顶部开启兼容模式。
- **可拖动徽标**：桌面端悬浮徽标位置可自由拖拽。
- **明 / 暗 / 跟随系统主题**。
- **快捷键** `Alt + X` 一键开关面板。
- **导入 / 导出备份**：一键备份全部数据为 JSON，导入时校验记录结构、数量与 URL 安全性。
- **自动清理**：可按天数自动清理旧记录，并限制最大存储条数（默认 1000 条）。
- **本地持久化**：全部数据存于浏览器 IndexedDB，**不联网、不上传**。

## 📦 安装

1. 先安装任意一个油猴类扩展：
   - [Tampermonkey](https://www.tampermonkey.net/)（推荐，Chrome / Edge / Firefox / Safari）
   - [Violentmonkey](https://violentmonkey.github.io/)

   直接从 GreasyFork [更好的 X（BetterX）](https://greasyfork.org/zh-CN/scripts/588748-更好的-x-betterx)安装。

2. 打开 [x.com](https://x.com)，页面左/右下角会出现应用徽标，点击或按 `Alt + X` 即可展开面板。

> 支持域名：`x.com` 与 `twitter.com`。

## 📖 使用指南

| 操作 | 说明 |
| --- | --- |
| 开关面板 | 点击页面左/右下角的徽标，或按 `Alt + X` |
| 搜索 | 在“帖子”页顶部搜索框检索作者 / 正文 / 备注 |
| 关键词 | 在“设置 → 关键词与排除词”输入（逗号分隔），可切换普通 / AND / 正则 |
| 排除词 | 在“设置 → 关键词与排除词”输入，命中即隐藏 |
| 内容净化 | 在“设置 → 内容净化”开启黄推过滤、选择强度，并设置自定义屏蔽词或账号白名单 |
| 界面净化与宽屏 | 在“设置 → 界面净化与宽屏”使用自动 / 手动宽度，或隐藏左右栏、推广、消息栏 / Grok 等元素 |
| 高级设置 | 在“设置 → 高级设置”调整自动清理、最大条数、闪现阈值、主题等 |
| 其他功能 | 在“设置 → 其他功能”开关 Firefox 兼容模式、广告过滤、媒体下载和取消年龄限制 |

## 🔒 隐私说明

- 所有帖子记录、备注、设置均**仅保存在你本机浏览器的 IndexedDB 中**，不会上传到任何服务器。
- 脚本仅在 `x.com` / `twitter.com` 运行，网络请求仅用于下载你主动选择的媒体（限于 `twimg.com` 等 X 官方域名）。
- “取消年龄限制”仅在本地 DOM 展示已能获取的媒体，**不会修改你的账号设置**。
- “内容净化”只检查页面已经渲染的作者与正文并添加可恢复的隐藏样式，**不会改写 X 接口数据，也不会自动拉黑或举报账号**。
- 开启“兼容 Firefox”后，为避免 Firefox 的 Xray / 油猴沙箱以及多个脚本重复包装网络 API 导致 X 卡在启动徽标，BetterX 不会改写页面的 `fetch` / `XMLHttpRequest`；该选项默认关闭，Chromium 浏览器不受影响。

## ❓ 常见问题

**Q：为什么有些帖子没被记录？**
A：只有在时间线中实际渲染过（滑到过）的帖子才会被捕获；可在“高级设置”里检查是否忽略了对应来源。

**Q：取消年龄限制后视频没显示？**
A：视频需要从时间线接口采集到真实地址，通常滑到该帖稍等片刻即可；图片则基本即时生效。

**Q：媒体下载超时怎么办？**
A：默认超时为 360 秒；超时后 BetterX 会询问是否重新下载，确认后会重试当前媒体。

**Q：为什么消息页或设置页没有宽屏？**
A：这两个页面的原生结构与时间线不同，强制加宽容易错位，因此 BetterX 会自动停用版面调整。

**Q：为什么 Firefox 以前可能一直停在 X 徽标？**
A：Firefox 的 Xray / 油猴沙箱在某些注入路径下无法安全共享网络函数；与广告过滤、媒体下载等其他 X 脚本叠加时尤其容易阻断启动。v1.8 首次检测到 Firefox 时会询问是否有异常；选择“有异常”，或在“设置 → 其他功能”开启“兼容 Firefox”，即可启用 v1.6.4 的启动熔断方案。该选项默认关闭，开启后帖子记录、面板、过滤、布局和 DOM 媒体兜底仍可使用，但部分视频 / GIF 下载、年龄限制视频和接口关注关系识别可能降级。切换此选项会自动刷新页面。

**Q：为什么宽度输入框里的数字会自动变化？**
A：默认开启“自动读取”，数字来自当前页面中 `[data-testid="primaryColumn"]` 和左侧导航实际元素的实时尺寸，只用于显示，不会强制改写 X 的布局。点击“应用宽度”后会切换为手动模式。

**Q：内容净化误隐藏了正常帖子怎么办？**
A：先确认“不审查已关注账号”已经开启，再切换到“保守”或把该账号加入白名单；关闭“隐藏黄推 / 成人引流机器人”会立即恢复当前页面的全部相关帖子。自定义屏蔽词按普通文本匹配，不会作为正则执行。

**Q：为什么“已识别关注”数量比实际关注数少？**
A：BetterX 只学习当前浏览过程中已经出现的关注关系，不会额外请求完整关注列表；Firefox 兼容模式不读取接口响应，主要依靠主页关注按钮和“正在关注”时间线学习，因此数量可能更少。“正在关注”时间线中的原创帖会跳过审查，转发帖默认按正文原作者判断。开启“不审查已关注账号的转发内容”后，已关注账号转发的第三方内容也会跳过。未识别的账号可手动加入白名单。

**Q：数据会丢吗？**
A：数据存在浏览器本地，清理浏览器数据会一并清除。建议定期用“导出备份”保存 JSON。
