4.3.0更新日志
- 优化通知同步性能：批量合并用户后统一采集变更、安排保存并刷新列表，避免逐用户重建界面；被动网络采集也按处理批次汇总通知更新，未变化的数据不触发额外保存或刷新。
- 优化通知历史保留：开启的订阅完整保留，关闭历史按置顶、最近更新优先占用常规 2,000 条容量的剩余名额；开启订阅本身超过 2,000 条时仍全部保留，避免旧关闭历史挤掉新订阅。
- 容量淘汰不再作为显式删除增量写回，避免误删其他标签页刚重新开启的用户；重新开启已被容量清理的历史记录后，也能正常保存和恢复。
- 修复同一 X 账号多标签页互相覆盖通知记录：按用户 ID 和本页实际改动的字段在数据库事务内合并，分别保留置顶、铃铛状态及较新的同步时间；显式移除记录不会被旧页面的资料或置顶增量复活，保存途中撤销修改也能正确落盘。
- 修复慢同步在铃铛保护期结束后覆盖较新操作的问题：同步及 fetch/XHR 采集记录读取时的状态版本，分页、响应或解析队列延迟超过五秒也不会回写操作前的旧状态，后续新请求仍可正常学习 X 原生铃铛变化。
- 修复用户改名后的重复通知记录与状态分叉：按稳定用户 ID 合并资料并保留置顶，兼容已有重复记录；操作锁按 ID 隔离，页面按钮同时核对登录账号及目标用户 ID，避免旧用户名被其他用户使用后误操作。
- 通知订阅按登录的 X 账号独立保存名单、开关状态、置顶和同步时间，切换账号时自动切换名单，退出登录后不再显示上一账号记录。旧版未标明所属账号的名单保留为旧记录，不擅自归到当前账号；各账号首次需重新同步建立独立名单。
- 隔离账号切换前启动的同步、铃铛请求及网络采集队列，旧响应和旧页面按钮不再修改新账号；延迟保存绑定原账号，数据库按账号原子合并，避免不同账号的标签页互相覆盖。备份包含各账号数据及旧版记录。
- 修复差异弹窗漏列用户：改为对当前本地全部开启记录与本次同步结果按 ID 求差集，资料更新时间、铃铛操作保护期及同步期间补入的本地记录不再被直接过滤；关闭操作仍会跳过打开弹窗后状态发生变化的用户。通知页及弹窗分开显示开启与已关闭记录数量。
- 通知同步后新增差异弹窗：列出本地仍开启、但本次未识别的用户及主页链接，说明账号注销、封禁、冻结或临时遗漏等可能原因，提供“取消”和“关闭以上用户通知”。按用户 ID 比对，已关闭记录不纳入待关闭名单。
- 批量关闭按并发 1、每次请求完成后间隔 1.5 秒执行，显示进度并支持取消后续队列；遇到限流或其他错误立即停止，不自动重试。仅在 X 明确返回目标账号不存在或已封禁时关闭本地记录，其余失败保留原状态；操作保留置顶并保存结果，切换 X 账号后不继续执行。
- 修复“同步订阅用户”误用“你关注的粉丝”接口、只枚举部分关系账号的问题：改为分页读取完整关注列表，并禁用该请求的浏览器缓存；统一通知状态及身份字段解析，JSON 错误、缺失或重复游标不再误报同步成功，合并时保留置顶并尊重刚修改的铃铛状态。
- 优化徽标首次显示：创建界面前同步恢复已保存的徽标样式、位置及主题，PC 圆形徽标与移动端半透明蓝色条直接以所选外观出现，避免等待数据库加载后再切换；数据库阻塞时面板入口和 Alt+X 仍可使用。
- 移植 LolipopJ 在 PR #3 贡献的作者链接功能：“常用功能”新增默认关闭的“作品详情页显示作者链接”，可在帖子详情和图片查看层直接打开作者简介中的 Pixiv、个人网站等链接，支持四语界面及站点图标。
- 修复作者链接的三个边界问题：复用节点与点击前重新核对作者、帖子及查看层；失败后按 1 秒、4 秒间隔自动重试，最多尝试三次，并保留手动重试入口；成功的空结果缓存一小时，避免重复请求无链接作者。
- 作者链接兼容新旧资料字段，接口错误不写入空缓存；切页、关闭功能或离开页面时清理重试，异步返回不会给已失效的帖子安装按钮。与原有截图、关闭功能和媒体选择共同集成到 4.3.0。
- “选择要下载的媒体”弹窗将“全选 / 全不选”改为“反选”：逐项翻转勾选状态，同步更新所选数量及下载按钮状态。
- 一键下载说明改为“长按或 Shift+点击可按缩略图选择要下载的图片、GIF 和视频”。
- 高级设置中的命名标签改为“媒体文件名（不含 .jpg 等扩展名）”，并同步简中、繁中、日文及英文界面。
- 补充作者链接、徽标首帧外观、通知同步与账号隔离回归；31 个检查脚本和 39 组本地浏览器回归全部通过，覆盖批量刷新计数、满额历史保留、账号切换、旧响应隔离、同账号及不同账号并发保存、慢分页保护、用户改名、完整关注分页、差异名单和串行关闭。

4.1.0更新日志

- 截图增加并发、资源大小、超时及输出像素限制，避免重复生成；保留页面原有 DOM、媒体播放状态和轮播位置。

- 完善长按与弹窗交互：滑动、移出和指针取消会撤销待触发的长按；阻止长按后的重复下载和触摸松手补发点击，支持取消按钮、Esc、点击遮罩、键盘焦点循环及焦点恢复。

4.0.0更新日志
- 修复内容净化词条归一化后重复计分的问题：大小写、全角与等价写法合并为同一词条，重复出现或跨评分分类出现都只计一次，并保留各写法的匹配能力。
- 修复 `hosts`、`central`、`events`、跨单词短句以及日期、版本号因空格或标点移除而误命中 `ts`、`ntr`、`91` 等词的问题；英文词和数字使用边界匹配，明确的较长词仍支持标点插入形式。
- 将多义短词、数字、常见医疗或生活用词及通用引流提示降为辅助信号，取消“主页、免费、妈妈、联系”等内置通用词的 99 分直拦；普通词与图片、链接或机器式用户名组合也不能代替成人内容证据。自定义屏蔽词、白名单、已关注账号豁免和原有均衡/保守阈值保持生效。
- 修复开启内容净化后，正常长帖正文被截断为 2,500 字符的问题；净化评分与帖子保存分别使用受限文本和完整正文，继续支持最多 100,000 字符，并避免重新抓取时用尚未加载完整的短文本覆盖已有长文。
- 修复多标签页同步或列表刷新覆盖正在输入的备注草稿的问题；正在编辑的区域保持在页面中，保留草稿、焦点、光标选区及浏览器原生撤销/重做历史，保存或取消后正确清理草稿。
- 加强自定义正则安全检查，修复通过多层括号隐藏嵌套重复或分支而绕过检查的问题；补充相邻量词、大小写及部分转义形式的判断，读取已有设置时过滤同类高风险规则。
- 修复大备份可以导出却因超过导入上限而无法恢复的问题；备份与筛选导出会自动按每卷不超过 25 MiB、20,000 条记录分卷，较大备份可在弹窗中逐卷保存。
- 导入支持一次选择多个 JSON 分卷，并按卷依次解析、写入；设置只确认和恢复一次，保留原有单文件备份兼容。后续分卷导入失败时会保留已成功写入的分卷，并提示可继续恢复。
- 优化动态帖子抓取调度：连续页面更新时仍按固定批次处理，避免抓取被不断延后而漏记短暂出现的帖子；重新启动观察器时会清理旧批次的计时器和待处理节点。
- 补齐分卷备份相关提示的简中、繁中、日文与英文翻译，并同步更新数据管理说明。
- 优化关键词与排除词匹配：按规则缓存校验和编译结果，避免每次筛选都为每条帖子重复创建正则；缓存设有容量限制，编辑规则后立即使用新规则。
- 优化面板刷新：只更新当前显示的帖子、通知或设置页签，隐藏页签在切换进入时读取最新状态；相同设置的后台同步不再触发重复刷新，显式恢复备份仍会完整恢复运行时状态。
- 优化帖子 ID 索引：未找到 ID 时直接返回，新增帖子同步维护索引，数组整体替换后只重建一次，避免缺失 ID 查询反复扫描全部记录。
- 新增针对长帖、备注编辑、危险正则、大备份分卷、持续页面更新、三项性能优化及内容净化误伤的回归验证；25 个检查脚本及 7 组本地浏览器回归全部通过。
