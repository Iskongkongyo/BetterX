4.0.0更新日志
- 修复内容净化词条归一化后重复计分的问题：大小写、全角与等价写法合并为同一词条，重复出现或跨评分分类出现都只计一次，并保留各写法的匹配能力。
- 修复 `hosts`、`central`、`events`、跨单词短句以及日期、版本号因空格或标点移除而误命中 `ts`、`ntr`、`91` 等词的问题；英文词和数字使用边界匹配，明确的较长词仍支持标点插入形式。
- 将多义短词、数字、常见医疗或生活用词及通用引流提示降为辅助信号，取消“主页、免费、妈妈、联系”等内置通用词的 99 分直拦；普通词与图片、链接或机器式用户名组合也不能代替成人内容证据。自定义屏蔽词、白名单、已关注账号豁免和原有均衡/保守阈值保持生效。
- 修复开启内容净化后，正常长帖正文被截断为 2,500 字符的问题；净化评分与帖子保存分别使用受限文本和完整正文，继续支持最多 100,000 字符，并避免重新抓取时用尚未加载完整的短文本覆盖已有长文。
- 修复多标签页同步或列表刷新覆盖正在输入的备注草稿的问题；正在编辑的区域保持在页面中，保留草稿、焦点、光标选区及浏览器原生撤销/重做历史，保存或取消后正确清理草稿。
- 加强自定义正则安全检查，修复通过多层括号隐藏嵌套重复或分支而绕过检查的问题；补充相邻量词、大小写及部分转义形式的判断，读取已有设置时过滤同类高风险规则。
- 修复大备份可以导出却因超过导入上限而无法恢复的问题；备份与筛选导出会自动按每卷不超过 25 MiB、20,000 条记录分卷，较大备份可在弹窗中逐卷保存。
- 导入支持一次选择多个 JSON 分卷，并按卷依次解析、写入；设置只确认和恢复一次，保留原有单文件备份兼容。后续分卷导入失败时会保留已成功写入的分卷，并提示可继续恢复。
- 优化动态帖子抓取调度：连续页面更新时仍按固定批次处理，避免抓取被不断延后而漏记短暂出现的帖子；重新启动观察器时会清理旧批次的计时器和待处理节点。
- 补齐分卷备份相关提示的简中、繁中、日文与英文翻译，并同步更新数据管理说明。
- 优化关键词与排除词匹配：按规则缓存校验和编译结果，避免每次筛选都为每条帖子重复创建正则；缓存设有容量限制，编辑规则后立即使用新规则。
- 优化面板刷新：只更新当前显示的帖子、通知或设置页签，隐藏页签在切换进入时读取最新状态；相同设置的后台同步不再触发重复刷新，显式恢复备份仍会完整恢复运行时状态。
- 优化帖子 ID 索引：未找到 ID 时直接返回，新增帖子同步维护索引，数组整体替换后只重建一次，避免缺失 ID 查询反复扫描全部记录。
- 新增针对长帖、备注编辑、危险正则、大备份分卷、持续页面更新、三项性能优化及内容净化误伤的回归验证；25 个检查脚本及 7 组本地浏览器回归全部通过。

2.4.0更新日志
- 新增“隐藏应用徽标（仅 PC）”，并支持通过油猴菜单快速显示 / 隐藏徽标。
- 新增 Tampermonkey GM 存储备份，网页 IndexedDB 被清理后可自动恢复 BetterX 设置。
- 新增 Node 回归测试，覆盖兼容模式、缓存、网络采集、媒体解析、ZIP 和下载并发等核心功能。
- 新增「启用自定义规则（屏蔽词与账号白名单）」开关，自定义屏蔽词、账号白名单不再受「隐藏黄推」影响。
- 新增 X 独立程序化广告位过滤，支持识别并隐藏 whoToFollowSspAd / SspAd 及 Google SafeFrame 广告卡片。
- 修复下载按钮误注入通知卡片及空帖子 ID 导致的任务串联问题。
- 修复 PC 长视频下载任务需要多次点击才能取消的问题，并加强请求中止处理。
- 优化ZIP 文件写入真实修改时间，并进一步完善超限保护。
- 优化桌面端与移动端下载任务入口，支持任务数量提示与快捷管理。
- 优化Firefox 兼容状态改用 GM 存储，备份不再保存浏览器专属兼容模式设置。
- 优化大型多媒体任务超过安全阈值时自动改为逐个保存，并及时释放下载缓存。
- 优化自定义屏蔽词为标签形式，支持回车、失焦或保存时添加，可点击 × 删除。屏蔽词自动去重，最多保存 50 个。
- 优化宽屏布局，时间线最小宽度降至 100px、左侧栏降至 50px；左侧栏自动切换为仅图标模式，并修复部分情况下侧栏宽度不生效的问题。
